# Prueba manual de usabilidad — Compras (tarjeta #220)

## Guía para moderar

Invitá a tres personas que no conozcan ObraSync. Probá con el mismo entorno y datos reales disponibles para las tres. No expliques dónde están las opciones ni cómo completar los pasos; leé solo las consignas. Pedí que piensen en voz alta y registrá dudas, retrocesos y errores sin intervenir. Si una tarea no se puede completar por falta de datos o permisos, anotá el bloqueo tal como ocurrió.

### Consignas

1. Encontrá una requisición y aprobala.
2. Identificá dónde publicar la licitación de esa requisición.
3. Encontrá la licitación y completá el proceso hasta adjudicarla.
4. Accedé a la Orden de compra generada.
5. Identificá cómo continuar el seguimiento hasta la recepción.
